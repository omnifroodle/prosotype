# Conformance vectors

Test vectors for the ProsoType packed stream, container version 1. The exact rules are in [SPEC.md §3.10](../SPEC.md).

- `inputs/*.json`: JSON-form inputs. The hand-written sample, plus three edge-case files covering pauses and speakers, escapes and folding, and quantisation edges. Each file's `source.note` says what it exercises.
- `expected/NAME.PROFILE.prs`: the exact bytes an encoder must produce for that input and profile.
- `expected/NAME.PROFILE.json`: what a decoder must return for those bytes. Numbers must match within 10⁻⁶; strings, booleans and nulls must match exactly. Key order does not matter.
- `manifest.json`: every vector, with its symbol count, header and total sizes, SHA-256 and extension phones.

How to check an implementation:

```bash
node js/test_vectors.mjs                                   # the JS decoder
cd prototype && uv run make_vectors.py --check             # the Python encoder and decoder
```

The vectors are generated by `prototype/make_vectors.py` and change only with a deliberate format change.
